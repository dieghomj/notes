# SandBox simulation — 企画書

> [!info] 概要
> 1ピクセル＝1粒子で世界のすべてがシミュレーションされる **2D 落ち物（Falling Sand）サンドボックスゲーム**。
> 砂・水・火・油・溶岩などの素材を置いて、流れる・燃える・溶ける・反応する様子を自由に楽しむ。
> エンジンは **自作（C++ / DirectX 11）**。

# 2. コンセプト

### ひとことで
**「世界のすべての粒が生きている、さわって遊ぶ箱庭」**

### コンセプトの柱
1. **すべてが動く** — 画面上のすべてのピクセルが素材として計算される。
2. **組み合わせで遊ぶ** — 素材どうしの反応（水＋溶岩 → 石＋蒸気 など）でプレイヤーが発見する楽しさ。
3. **さわって気持ちいい** — ブラシで描く、壊す、燃やす。触ったらすぐ反応が見える。

---
# 3. ターゲット

- 物理シミュレーションや「眺めて気持ちいい」系が好きなプレイヤー
- *Minecraft* / *Terraria* のようにルールのない遊び場が好きな人
- 短時間でも遊べる、スキマ時間に触れるおもちゃを求める人

# 4. ゲームシステム

## 4-1. 基本ループ
```
素材を選ぶ → ブラシで置く → シミュレーションを眺める → 反応を発見 → さらに試す
```

## 4-2. 素材（初期案）

| 種類 | 素材 | ふるまい |
|---|---|---|
| 粉体 | 砂、土、灰 | 下に落ちて積もる（斜めにも崩れる） |
| 液体 | 水、油、溶岩、酸 | 落ちて横に広がる。密度で上下が入れ替わる（油は水に浮く） |
| 気体 | 蒸気、煙 | 上に昇って広がり、時間で消える |
| 固体 | 石、木、金属、ガラス | 動かない。燃える・溶けるなどで状態変化 |
| エネルギー | 火 | 燃えるものに広がり、時間で消える |

## 4-3. 反応（例）

| 組み合わせ | 結果 |
|---|---|
| 水 ＋ 溶岩 | 石 ＋ 蒸気 |
| 火 ＋ 木 / 油 | 燃え広がる → 灰・煙 |
| 酸 ＋ 金属 / 石 | 溶かす（酸も減る） |
| 蒸気（冷える） | 水に戻る |
| 砂 ＋ 高温 | ガラス |

## 4-4. ツール
- ブラシ（サイズ変更）、消しゴム、塗りつぶし
- 一時停止 / コマ送り / 速度変更
- セーブ / ロード（ステージをファイルに保存）

## 4-5. ゲームモード（案）
- **サンドボックス** — 制限なしで自由に遊ぶ（メイン）
- **チャレンジ**（後回し） — 「水をゴールまで運べ」「この塔を燃やせ」のような目的つきステージ

---
# 5. セールスポイント

- 数百万ピクセルが **リアルタイムで全部動く** 迫力
- 素材の反応を **自分で発見する** 楽しさ
- 自作エンジンならではの **軽さ・処理の速さ**（マルチスレッド化）

# 8. 技術仕様

## 8-1. エンジン構成（自作 C++ / DX11）
```
App（ウィンドウ / 入力）
 ├─ World         … セルのグリッド（uint8_t material[W*H] ＋ 追加データ）
 │    └─ Chunk[]  … 64×64 のチャンク、dirty rect で更新範囲を管理
 ├─ Simulator     … セルオートマトン更新（素材ごとのルール）
 ├─ Renderer      … グリッド → テクスチャ転送 → フルスクリーン quad 描画
 └─ UI            … Dear ImGui（パレット・デバッグ表示）
```

## 8-2. 処理の工夫
- **チャンク ＋ dirty rect** — 変化した場所だけ更新する
- **チェッカーボード式マルチスレッド** — 隣り合わないチャンクを4パスで並列更新（*Noita* の GDC 講演の方式）
- **1フレーム1回の移動** — 更新済みフラグで同じ粒が二重に動かないようにする
- **描画** — パレット（素材ID → 色）を使うピクセルシェーダ、ポイントサンプリング

## 8-3. 将来の拡張
- 剛体（Box2D）— つながったピクセルの塊を物理オブジェクトにする
- 温度シミュレーション
- GPU（コンピュートシェーダ）での更新
